# AGENTS.md

Scope: `book/` — the Proptest Book, the mdBook (`book.toml`, sources under `src/`) that is the user guide for both `proptest` and `proptest-derive`. For workspace commands, architecture, and commit conventions see the workspace-root `AGENTS.md`.

## Structure

`src/SUMMARY.md` defines the navigation: `intro.md`, then a `proptest/` part (getting-started, strict — the panic-free `proptest::strict` runner chapter, the 13-chapter `tutorial/`, failure-persistence, forking, no-std, wasm, limitations, vs-quickcheck, reference-docs, state-machine, tips-and-best-practices) and a `proptest-derive/` part (getting-started, modifiers, errors). A chapter added on disk is invisible until it is also added to `SUMMARY.md`.

## Couplings — why editing a chapter is rarely a one-file change

- **Four chapters are also the README sources.** `proptest/README.md` is generated by `proptest/gen-readme.sh` from the intro, getting-started, vs-quickcheck, and limitations chapters (plus `readme-prologue.md`/`readme-antelogue.md`), and the repo-root `README.md` is a symlink to it. Editing any of those chapters means regenerating the README — never hand-editing it.
- **Chapters reproduce example code and real program output.** `proptest/getting-started.md` quotes `proptest/examples/dateparser_v1.rs`/`dateparser_v2.rs` (including exact failure output), `proptest/forking.md` quotes `fib.rs`, and `tutorial/strategy-basics.md` / `tutorial/shrinking-basics.md` quote `tutorial-strategy-play.rs` / `tutorial-simplify-play.rs`. An example and its chapter must change together — see `proptest/examples/AGENTS.md`.

## Building and publishing

- `mdbook build` (run inside `book/`) builds the site.
- `book/gen-docs.sh` is the maintainer-only publisher: it runs `mdbook build` and deposits the result into a local GH-Pages checkout using absolute paths — not part of normal development. The repo-root `gen-docs-all.sh` chains the `proptest` rustdoc builds (`std` and `nostd` variants) with this script.

## Prose style

The book's markdown is historically hard-wrapped at ~80 columns; when editing existing chapters match the surrounding file, and don't reflow untouched lines (root `AGENTS.md`, "Conventions & gotchas").
