### Panic-free properties with `proptest::strict`

This fork also provides the panic-free `proptest::strict` module (feature `strict-test`, enabled by default). Property closures return `Result<A, E>` and the runner returns a typed `PropertyResult`: successful subjects and concrete failures remain intact, with the minimized native counterexample in `PropertyCause::Falsified`. In-process evidence may borrow data and need not implement `Clone`, `Send`, `Sync`, or serialization traits. Default strict runs use deterministic seeds selected by `STRICT_TEST_SEED` and disable regression-file persistence; explicitly supplied configurations preserve their persistence and seed choices. Forked execution uses an explicit `PropertyTransport`. The book's [Strict property tests](https://proptest-rs.github.io/proptest/proptest/strict.html) chapter covers assertions, reports, configuration, and `#[property_test]`.
